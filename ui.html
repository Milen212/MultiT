USB encrypt

Lock a USB drive with your own password. Every file — and its name — is encrypted with AES-256-GCM; your password unlocks a random 256-bit key (scrypt). Each file is verified before its original is removed.

!
Your password is the only key. Forget it and the files are gone — nobody, including MultiT, can recover them. Unplugging mid-way is safe (originals are only removed after their encrypted copy is verified), but let it finish.

Folder vaults

Lock any folder with your own password — same AES-256-GCM engine as USB encrypt, but at SSD speed. File names are hidden too.

!
Forget the password and the files are gone. Windows, program folders and your top-level profile folders (Desktop, Documents…) can't be locked — pick a folder inside them.
